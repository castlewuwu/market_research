```
┌─────────────────────────────────────────────────────────────┐
│                    VeighNa量化交易系统                        │
├─────────────────────────────────────────────────────────────┤
│                                                               │
│  ┌─────────────────────────────────────────────────────┐    │
│  │              vnpy.alpha (AI策略引擎)                  │    │
│  │  ┌───────────┐  ┌───────────┐  ┌───────────┐        │    │
│  │  │  dataset  │  │   model   │  │ strategy  │        │    │
│  │  │ 因子工程   │  │ 模型训练  │  │ 策略生成  │        │    │
│  │  └───────────┘  └───────────┘  └───────────┘        │    │
│  └─────────────────────────────────────────────────────┘    │
│                                                               │
│  ┌─────────────────────────────────────────────────────┐    │
│  │              vnpy.trader (交易核心)                   │    │
│  │  ┌───────────┐  ┌───────────┐  ┌───────────┐        │    │
│  │  │   event   │  │  engine   │  │   ui      │        │    │
│  │  │ 事件引擎  │  │ 主引擎    │  │ 界面      │        │    │
│  │  └───────────┘  └───────────┘  └───────────┘        │    │
│  └─────────────────────────────────────────────────────┘    │
│                                                               │
│  ┌─────────────────────────────────────────────────────┐    │
│  │              Gateway接口层                            │    │
│  │  XTP  CTP  TORA  OST  EMT  IB  ...                   │    │
│  └─────────────────────────────────────────────────────┘    │
│                                                               │
└─────────────────────────────────────────────────────────────┘
```

**关键组件**:
- **EventEngine**: 事件驱动核心，解耦各模块
- **MainEngine**: 主引擎，统一管理gateway和app
- **Gateway**: 交易接口封装，支持CTP/XTP等
- **App**: 策略应用，如cta_strategy、portfolio_strategy
